# Kit de versionamento - SD-Project-ToneForge

Este pacote contem arquivos iniciais para configurar um fluxo de Git/GitHub profissional no projeto.

## Arquivos

- `docs/GIT_FLOW.md`: documentação principal do fluxo.
- `.github/pull_request_template.md`: template de Pull Request.
- `.github/ISSUE_TEMPLATE/bug_report.md`: template de bug.
- `.github/ISSUE_TEMPLATE/feature_request.md`: template de feature.
- `.github/CODEOWNERS.example`: exemplo de donos de codigo.
- `.gitmessage.txt`: template local de mensagem de commit.
- `.gitignore.example`: exemplo de gitignore.
- `templates/ci.yml`: modelo de GitHub Actions. Copie para `.github/workflows/ci.yml` quando for adaptar para a stack real.

## Como usar

Copie os arquivos para a raiz do repositório e ajuste os usuários, nomes de times, comandos de build e testes.
